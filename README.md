# Nannd2tetris Hack Computer Emulated with Synthesizable VHDL Code

* **Description:** This project is based on the Hack computer described in "The Elements of Computing Systems: Building a Modern Computer from First Principles" by Noam Nisan and Shimon Schocken. The computer architecture is very similar to the Hack computer, and it can run Hack assembly machine code. All of the components are designed in VHDL, can be simulated in any hardware design platform such as AMD Vivado or Intel Quartus, and are synthesizable. This project is perfect for educational demonstration purposes or to help learn digital design. Additionally, since the designs in this project are synthesizable, it is possible to expand upon the project and potentially load this design onto an FPGA or an SOC and have a working computer architecture in real life hardware. In the "Design Sources" folder of this repository are the designs of the ALU, program counter, CPU, Memory, ROM, and the full computer design. In the "Simulations" folder are the simulations of each of the corresponding components. Note: simulation.vhd is the simulation for the ALU. 

* **Installation Instructions:** This computer was designed and simulated in Vivado (2024 version). Install the latest version of Vivado or any other hardware design platform. Download all of the .vhd files found in this repository in the "Design Sources" folder, then open them in a new project. To simulate the whole computer design download the Computer_sim.vhd simulation source from the "Simulations" folder. To easily see the outputs of the computer, the memory is designed so that when R4 is changed to a '1', the memory outputs the present state of registers 0 through 3. Inside ROM.vhd, there is a prewritten default program that based on numerical user input (up to 255), the program will find the sum of the input and all of the values less than it and output it to R1. 
If you want to try out different programs, go to the nand2tetris ide, and from the Assembler it is possible to generate binary code instructions translated from Hack assembly. If necessary, load the instructions in the nand2tetris CPU emulator to run and test the program. When satisfied with the software, proceed to the ROM.vhd file and change the existing case statement with the new machine code instructions. If needed, change the Computer_sim.vhd simulation process to correspond to the desired behavior of the simulation. Save the changes in both the ROM.vhd and the Computer_sim.vhd and run the behavioral simulation. The results should match the results from the nand2tetris CPU emulator. For especially long programs, feel free to use the conv_to_VHDL.py program. Run the program, copy and past the machine code output from the nand2tetris assembler, enter the total number of instructions, and press enter. The program will automatically print the corresponding VHDL-based syntax that can be pasted straight into the ROM.vhd case statement. 
To test out the components individually, download that component's design source and its corresponding simulation file, and load both into your hardware design platform. Change the simulation file's process if desired. 
The main difference is that this project does not have any screen functionality, so it is not possible to emulate any programs that involve the screen. Also for simplicity, the size of the memory is only 256, not ~32K like the Hack computer. The keyboard address however remains as 24576 for compatibility with Hack assembly.
